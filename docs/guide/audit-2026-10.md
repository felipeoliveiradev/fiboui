# Audit — October 2026

What shipped in this pass, which old bugs still exist on other components, and what the library still does not do. Ten read-only passes covered docs, inputs, the React `type` stamp, CSS fluent coverage, form validation, signals, List, public types, repeated bug classes, and missing APIs.

## What shipped

| Piece | Where | Behavior |
| :--- | :--- | :--- |
| List row chrome | `List().itemStyle / itemHover / itemActive / itemFocus` | CSS fluent proxy. `paddingHorizontal` maps to left/right. A later longhand expands a previous shorthand on the list style store. `boxShadow(0)` becomes `none`. |
| Logical axes everywhere | `FiboBuilder`, `PseudoStateBuilder` | `paddingHorizontal`, `paddingVertical`, `marginHorizontal`, `marginVertical`, and the X/Y aliases. Hover, focus, and active use the same proxy. |
| Main axis | `.justifyContent('between')` | Also accepts `space-between` and `spaceBetween`. `.alignItems` stays the cross axis (`start`, `center`, `end`, `stretch`). |
| TextField typing | `TextField` | Uncontrolled (`defaultValue`). `.controlled(true)` opts into React state. A signal patches `input.value` without `setState`. `.onCommit` fires on blur. The mask writes the DOM. |
| Form | `Form` | Native submit. Order: validation, `beforeSubmit` (`false` cancels), `onSubmit`, `afterSubmit`. Second argument is `FormControl`: `reset()`, `reset(name)`, `set(name, value)`, `errors`. |
| Validation | `required`, `minLength`, `maxLength`, `email`, `pattern`, `min`, `max`, `rule` | `.validation(schema)`, `.errorMode('field' \| 'below' \| 'manual')`, `.onInvalid`. `TextField().rules(...)`. |
| Submit button | `Button().submit()` | `.htmlType()` / `.reset()`. `.type()` is the React element type and does not set the attribute. |
| List signal | `listSignal` / `collection` | `add`, `insert`, `set`, `update`, `remove` / `delete`, `find`, `search`, plus `clear`, `replace`, `filter`, `map`, `move`. Each item gets `_id`. |
| Live count | `` Text(`Total ${todos.$length}`) `` | `$length` embeds a marker. `Text` auto-binds only the signals inside that string. Extra `.bindSignal(other)` still works. `.bindSignal(sig, format)` replaces the text. |
| Live list | `List().items(todos).renderItem(...)` | Subscribes that list signal only. Row key prefers `_id`. |
| Types | `npm run build:dts` | Writes `dist/index.d.ts`. `vite build` alone does not. |

`import { Form, required, listSignal, interp } from 'fiboui'` matches `src/index.ts` and the current `dist/index.d.ts` (233 names). `FormErrorMode` is not a root export. `fiboui/interactive` does not re-export `Form`.

## Same bugs, other components

### Typing and form state

`TextField` is the only control that is uncontrolled by default and the only one with `.rules()` and its own error line.

| Component | What still happens |
| :--- | :--- |
| `Textarea` | Always passes `value`. Typing sticks only if a parent `setState`s. Submit sees the initial string. `form.reset(name)` is overwritten on the next render. |
| `Checkbox`, `Switch` | Controlled `checked`, no `.name()`. Absent from `FormData`. Reset cannot find them. |
| `RadioGroup` | Named, but `checked` follows the `.value()` prop. Submit sees the initial selection. |
| `Select` | Custom listbox, no native control, no `.name()`. |
| `Combobox` | Search input calls `setSearchTerm` on every key. No `.name()`. |

### `.type()` is still swallowed

The proxy returns the stamped React `type` before builder methods. Renaming fixed `Button`. These methods never run:

- `TextField().type('email' \| 'password' \| …)` — the input stays `type="text"`. `.props({ type: 'email' })` is the path that works today.
- `Text().type('h1')` — the tag stays the default. `.variant('h1')` works.
- `InputCard().type(...)` — same stamp, then it calls `TextField().type(...)`.

### Signals freeze outside `Text`

`` `Total ${todos.length}` `` is a number before any builder sees it. Use `$length`.

Only `Text` (and components that render through `Text`, such as `Badge` text and several card bodies) resolve interpolation markers. These store the raw string and never subscribe: `ListTile` title and subtitle, `Label`, `Button('…')`, `Alert` title and description, `Banner`, `Card` text, and field labels on `TextField`, `Textarea`, `Select`, `Checkbox`, and `Switch`.

`Table().data(listSignal)` does not call `bindSignal`. `List().items(fn)` runs the function once. `listSignal.search()` and `.filter()` return a plain array, so a list built from them does not stay live. In-place mutation (`todos.value[0].title = …`) does not notify.

### CSS that still skips the normalizer

Unknown methods on builders, pseudo-states, and list item callbacks go through `normalizeCssValue`. These paths do not:

- `.style()`, `.css()`, and `.media()` objects. `boxShadow: 0` stays numeric and React emits `0px`.
- `List().itemStyle({ … })` when you pass an object instead of a callback.
- `.shadow(0)` on `FiboBuilder`. `0` is falsy, so it registers the `md` preset. `.boxShadow(0)` is the path that becomes `none`.
- `expandBoxShorthand` runs on the list style store. On `FiboBuilder` and hover/focus/active, a later `.padding()` can still reset an earlier `.paddingHorizontal()`.

`ShapeBuilder` (`Circle`, `Rect`, `Path`) has a fixed method list and no CSS proxy. An unknown method throws.

### Other repeats

- `Button` ripple reads `e.currentTarget` inside `import(...).then(...)`. After the await it is `null`, so the ripple no-ops. `Form` already copies the element before `await`.
- `pattern(/…/g)` does not reset `lastIndex`, so a global regex alternates pass and fail.
- Disabled named fields are omitted from `FormData` and then fail `required` as `''`.
- The browser's own constraint validation can block `submit` before `runFieldRules`. `noValidate` is not set by default.
- List `itemHover` / `itemActive` / `itemFocus` share one `<style id="fibo-list-custom-styles">`. The last list to mount replaces the sheet for every list.
- `itemFocus` uses `:focus` on a `div` with no `tabIndex`, so it does not match.
- Virtualized lists (over 100 rows) key height by index and do not clear it when a row is removed.

## Not built yet

Ranked for the todo page and the next form.

1. List empty state. An empty `listSignal` renders a blank column.
2. Validation on blur or while typing. Rules run only inside submit. Painted errors stay until the next submit.
3. `aria-invalid` and `aria-describedby` on the error line.
4. `Checkbox`, `Switch`, `Select`, and `Combobox` as named fields with `.rules()`.
5. `Textarea` uncontrolled, with the same error hook as `TextField`.
6. Touched / dirty, and `isSubmitting` that can disable the submit button.
7. `equalTo`, `url`, integer, checkbox-must-be-checked, async rules. `rule()` covers sync cases. A `check` that returns a `Promise` is truthy, so it always passes.
8. Helper text and a clear button on `TextField`.
9. Validation messages are English unless you pass your own string.
10. `FormErrorMode` is not exported from the package root. Subpath `fiboui/interactive` does not export `Form`.

## Docs that were stale

Before this update, the site had no Form page. TextField was documented as `.value()` / `.type()`. List `.items` was typed as `T[]` only. State management did not mention `listSignal` or `$length`. Button had no `.submit()`.
