# Audit — October 2026

What shipped in 2.5.0–2.6.4 and Waves 1–6, which product gaps remain, and what the library still does not do. Earlier rows in this file that said “`.type()` swallowed”, “Checkbox/Select have no `.name()`”, “FormData missing”, “ripple null after await”, “one shared list stylesheet”, “Textarea always controlled”, “Button `.type` does not set the DOM”, “List has no empty state”, “ShapeBuilder has no CSS proxy”, “`resetStyle` does not wipe classes”, “Combobox Enter swallows submit”, “multi-select is a comma string”, “`fiboui/interactive` does not export `Form`”, “nested `Outlet` is dead”, “`ShapeBuilder.style` replaces `_style`”, “`_clipPath` is not stamped”, “DefaultErrorPage Go Home ignores `basename`”, “TextField has no helper / clear”, “interp lives only in `Text`”, “Card text stores the raw string”, “`listSignal.search()` / `.filter()` return a frozen array”, “no `url` / `integer` / `equalTo` / `data-submitting` / blur validation”, “`FiboApp.mount()` skips StrictMode”, “Plugin SSR leaks across requests”, “SVG `drop-shadow(… inset)`”, “JS `--fibo-shadow-*` vs CSS `--fibo-elevation-*`”, or “`dist/interactive.js` has no `Form`” are **wrong now** — they shipped.

## What shipped

| Piece | Where | Behavior |
| :--- | :--- | :--- |
| List row chrome | `List().itemStyle / itemHover / itemActive / itemFocus` | CSS fluent proxy. `paddingHorizontal` maps to left/right. One stylesheet **per list** (`fibo-list-custom-styles-${id}`). `itemFocus` uses `:focus-within`. `boxShadow(0)` becomes `none`. |
| List empty | `List().empty(...)` | String, node, builder, or factory. String markers (`$length` / `interp`) stay live. Paints `.fibo-list-empty` when there are no rows (plain array, empty `listSignal`, or `items(fn)` → `[]`). Hidden when rows exist. |
| Logical axes everywhere | `FiboBuilder`, `PseudoStateBuilder` | `paddingHorizontal`, `paddingVertical`, `marginHorizontal`, `marginVertical`, and the X/Y aliases. Hover, focus, and active use the same proxy. |
| Main axis | `.justifyContent('between')` | Also accepts `space-between` and `spaceBetween`. `.alignItems` stays the cross axis (`start`, `center`, `end`, `stretch`). |
| TextField typing | `TextField` | Uncontrolled (`defaultValue`). `.controlled(true)` opts into React state. A signal patches `input.value` without `setState`. `.onCommit` fires on blur. The mask writes the DOM. `.type('email')` sets the input type. Password eye has `aria-label`. `.helper(text)` paints a helper line under the field. `.clearable()` shows a clear control when there is a value. |
| Other fields | `Textarea`, `Checkbox`, `Switch`, `RadioGroup` | Uncontrolled by default. `.name()` so `FormData` sees them. `.controlled(true)` opts back into parent state. `.rules()` attaches field checks. Unnamed `RadioGroup` stays out of `FormData`. Static `.error()` on Checkbox/Switch sets `aria-invalid` / `aria-describedby`. Switch has `aria-checked`. Indeterminate is `mixed`. |
| Select / Combobox | `Select`, `Combobox` | `.name()` writes hidden input(s) for submit. Multi-select is **one hidden per value** (same `name`) → `FormData` `string[]`. Combobox Enter only `preventDefault`s when the list is open **and** there is a highlight / `onAdd` to commit; otherwise the form submits. |
| Form | `Form` | Native submit. Order: validation, `beforeSubmit` (`false` cancels), `onSubmit`, `afterSubmit`. Second argument is `FormControl`: `reset()`, `reset(name)`, `set(name, value)`, `errors`. `noValidate` by default. Disabled fields are skipped. `/g` patterns do not alternate. Errors set `aria-invalid` and clear while typing. Rules also run on blur. While `onSubmit` is in flight the `<form>` is `data-submitting` / `aria-busy` (a second submit waits). Field host and form get `data-touched` on blur and `data-dirty` on input. `javascript:` / `data:` `action` is dropped. |
| Form exports | `fiboui`, `fiboui/interactive` | `import { Form, required, FormErrorMode } from 'fiboui'` and `import { Form, required } from 'fiboui/interactive'`. `FormErrorMode` is a type (`'field' \| 'below' \| 'manual'`). |
| Validation | `required`, `minLength`, `maxLength`, `email`, `url`, `integer`, `pattern`, `min`, `max`, `equalTo`, `rule` | `.validation(schema)`, `.errorMode('field' \| 'below' \| 'manual')`, `.onInvalid`. `TextField().rules(...)` and the other named fields. A `check` that returns a `Promise` is awaited. Rules run on blur as well as submit. |
| Submit button | `Button` | `.type('submit' \| 'reset' \| 'button')` sets the HTML `type` (2.6.0). `.submit()`, `.reset()`, and `.htmlType()` do the same. Ripple captures the button **before** the dynamic import. |
| `.type()` methods | `TextField`, `Text`, `InputCard`, `Button` | Builder methods named `type` run. The React element stamp no longer swallows them. |
| List signal | `listSignal` / `collection` | `add`, `insert`, `set`, `update`, `remove` / `delete`, `find`, `search`, plus `clear`, `replace`, `filter`, `map`, `move`, `view()`, `viewWhere()`. Each item gets `_id`. `search(query)` is a live `view()` plus a copy of the visible rows. `filter(fn)` is a one-shot snapshot of `_source` (does not change `.value`; safe inside `computed`). `viewWhere(fn)` is the live predicate (AND with the query); `viewWhere()` clears it. Bound `List` / `Table` subscribe to the signal itself. In-place `list.value.push` / `list.value[0].title = …` does **not** notify (by design). `set` / `add` / `update` assign a new array. |
| Live count | `` Text(`Total ${todos.$length}`) `` | `$length` embeds a marker. `Text`, Label, Alert, ListTile, Button, Banner, Card (`.text` / `.subtitle` / `.number` and string children), and field labels auto-bind the signals inside that string. Extra `.bindSignal(other)` still works. `.bindSignal(sig, format)` replaces the text. |
| Live list | `List().items(todos).renderItem(...)` | Subscribes that list signal only. Row key prefers `_id`. `List().items(fn)` re-runs on each rebuild. Virtual cache keys by `_id`. |
| Table / Tags | `Table().data(listSignal)` | Binds the list signal. Row keys prefer `_id`. |
| CSS objects | `.style()` / `.css()` / `.media()`, `itemStyle` object | Values go through `normalizeCssValue`. `hover.shadow(0)` is `none`. |
| `resetStyle()` | `FiboBuilder` | Clears `_classNames`, `_style`, `_cssStyles`, `_boxLonghands`, then adds `fibo-reset`. Later helpers stamp again. |
| Shape CSS proxy | `Circle`, `Rect`, `Path` | Unknown methods merge into `_style`. `.style({…})` **merges** (does not replace). `clipPath` is stamped on the SVG node. SVG `shadow(dx, dy, blur, color)` stays a 4-arg drop-shadow. |
| LinearGradient / Canvas | `LinearGradient`, `Canvas` | `LinearGradient.build()` returns `<defs>`. `.fill(gradient)` is `url(#id)`. Canvas spreads host props; default `overflow="visible"`. |
| Nested routes | `Router` + `Outlet` | Parent with `children` is a layout (prefix match). `Outlet` renders the child and provides current-route context. `useRouteMeta()` reads the leaf. Guards run on the full chain. |
| DefaultErrorPage | `DefaultErrorPage` | “Go Home” is `<a href={joinBasename(basename, '/')}>`. Crash UI is `role="alert"`. Empty `Error.message` falls back. Try Again always shows. |
| Link schemes | `Link` | `javascript:` / `data:` / `vbscript:` / `file:` omit `href` and cancel click. `target="_blank"` merges `noopener noreferrer`. |
| Theme | `FiboThemeProvider` | JS tokens match the CSS sheets. Provider default is **`material`** (same as `base.css`). `themeToCssVars` publishes `--fibo-elevation-*` (same names as the sheets). |
| Wave 4 P1s | layout / content / Grid / persist | Sidebar works without a Router (`<nav aria-label="Sidebar">`). Empty `Line()` is `<hr>`. Column/Center `min-h-0`. Badge intent roles + unknown-intent fallback. `Text` coerces object / JSX / InterpToken children. Grid is real CSS (`repeat(n, minmax(0, 1fr))`, not JIT Tailwind). Asset/Collection images have `alt`. Storage / persist are SSR-safe. `scrollTo` on an invalid id is a no-op. Pan cancel fires `onEnd`. |
| Types | `npm run build:dts` | Writes `dist/index.d.ts`. `vite build` alone does not. |
| `FiboApp` StrictMode | `FiboApp.mount()` | Wraps `StrictMode` by default (`strict: false` opts out), same as `mount()`. |
| Plugin SSR | `PluginManager` | Resets per SSR request. Routes, stores, and services do not leak across `renderToString`. |
| SVG inset shadow | icon filters | No `drop-shadow(… inset)` (invalid CSS filter; the browser ignored it). |
| `fiboui/interactive` dist | `vite build` | Writes `Form` and the validation helpers on `dist/interactive.js`. |

`import { Form, required, listSignal, interp, FormErrorMode } from 'fiboui'` matches `src/index.ts`. `fiboui/interactive` re-exports `Form`. Nested `Outlet` / `lazyRoute` / `useRouteMeta` live on the navigation barrel (`fiboui/navigation`). There is no `Chip()` or `IconButton()` factory.

## Remaining (honest)

The Wave 6 product-skip / P2 rows and the Wave 7 leftovers above shipped: Card interp, Avatar status pip, VirtualColumn key cache, Combobox / RadioGroup / Progress / Table / Tags / List empty interp, Grid `.rows` / `.templateColumns` / `.colStart`, `url()` http(s) only.

True leftover:

- Default validation messages are English (by design — pass your own string).

## Docs that were stale

The Form page, TextField, Button, Text, List, Checkbox/Switch, Select/Combobox, routing, and this audit previously described 2.4-era (and Wave 1 leftover) bugs as current. They now match 2.5–2.6.4 + Waves 1–6. Card `.text` / `.subtitle` / `.number` and string children bind interp. `listSignal.filter(fn)` is a snapshot of `_source`; `viewWhere(fn)` is the live predicate. W4-03 already refreshed the component pages; this file now matches the shipped contract (`TextField().helper()` / `.clearable()`, live `search` / `viewWhere`, interp on Label/Alert/ListTile/Button/Banner/Card/Combobox/RadioGroup/Progress/Table/Tags/List empty/field labels, `url` (http/https only) / `integer` / `equalTo` / `data-submitting` / blur validation, Grid `.templateColumns` / `.rows` / GridItem `.colStart`, `FiboApp` StrictMode, Plugin SSR reset, SVG no inset drop-shadow, theme `--fibo-elevation-*`, `dist` Form after `vite build`). No leftover “not built yet” row remains in `docs/components/*` for APIs that shipped.
